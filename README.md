# Yoshua Bengio Paper Replications

Educational **PyTorch** implementations of the most influential research papers by **Yoshua Bengio and his collaborators**.

This repository follows the evolution of modern deep learning, from the **vanishing gradient problem** and **neural language models** to **representation learning**, **deep learning**, **attention**, **self-supervised learning**, **generative modeling**, and **AI safety**.

---

## Goals

- Read and understand Yoshua Bengio's landmark research papers.
- Reproduce the core algorithms in PyTorch.
- Build clean, educational implementations from scratch.
- Visualize architectures, learning dynamics, and representations.
- Document implementation details, assumptions, and simplifications.
